### 生鲜水产小程序

微信小程序形态的生鲜商品业务系统，覆盖商品展示、下单、订单详情与后台管理。

- **技术栈**：微信小程序（TypeScript + SCSS）、`miniprogram` 业务目录、独立 TypeScript 类型声明
- **业务模块**：商品与规格选择、购物车与下单、订单状态流转、订单详情页
- **工程实践**：ESLint + TypeScript 严格模式；微信开发者工具工程配置与本地私有配置分离
